# StudyShare — independent copy

This copy has had Replit-only project configuration and Vite development plugins removed.

## Important
- The original Replit project/ZIP should be kept as a backup.
- This project still requires its PostgreSQL database and environment variables to run.
- The database has NOT been migrated in this cleanup.
- Run `pnpm install` to generate a fresh `pnpm-lock.yaml`.
- Then use the workspace build/dev scripts to test the app.

## Remaining deployment work
1. Install dependencies and test the build.
2. Set up an independent PostgreSQL database.
3. Configure required environment variables.
4. Deploy the frontend/backend.
5. Connect your own domain and HTTPS.
